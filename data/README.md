# External/reference material

`geant4-examples/UserData/` and `references/rdecay01/` retain inherited Geant4
example data and reference text with their original readmes. They are not the
installed Geant4 nuclear datasets and are not automatically loaded by the CYGNO
application. `Geant4-LICENSE` preserves the upstream license. Current run
validation is documented in [validation/README.md](../validation/README.md).
